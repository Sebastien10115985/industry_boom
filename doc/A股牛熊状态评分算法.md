# A股牛熊状态评分算法 — 实现规格

> 拉取上证50、沪深300、中证500、创业板指、科创50五个宽基指数K线数据，缓存在本地，并且界面可更新数据。基于这五个数据，按下面算法计算。
> 目标产出：对 5 个宽基指数分别给出一个 −100~100 的分值，并合成一个全市场综合分，判定当前处于熊市 / 震荡市 / 牛市。

---

## 1. 目标与范围

| 项 | 定义 |
|---|---|
| 输入 | 5 个宽基指数的日线 OHLCV |
| 输出 | ① 每个指数一个分值 `S_i` 与状态；② 一个综合分 `S` 与状态；③ 广度读数 |
| 分值域 | `[-100, 100]` |
| 状态分档 | `S < -20` 熊市；`-20 ≤ S ≤ 20` 震荡市；`S > 20` 牛市 |
| 计算频率 | 每个交易日收盘后计算一次（用当日已收盘数据，禁止用未来数据） |

## 3. 数据层

- **数据源**：`akshare`（免费、无需密钥）。推荐接口 `ak.index_zh_a_hist(symbol, period="daily", start_date, end_date)`；备选 `ak.stock_zh_index_daily(symbol="sh000016")`。接口返回列名以实际版本为准，实现时做列名适配。
- **数据区间**：至少 6 年，建议 8~10 年（分位标准化需要 5 年窗口，回测需要跨完整牛熊周期）。
- **字段**：`date / open / high / low / close / volume`，指数无需复权处理。
- **本地缓存**：拉取结果落盘为 CSV 或 parquet，避免每次运行重复请求；提供 `force_refresh` 参数。
- **日期对齐**：5 个指数取交易日期交集，缺失值用前值填充（forward fill），并标记填充位置。
- **失败处理**：任一指数拉取失败则中止本次计算并明确报错，禁止用旧数据静默代替。

## 4. 算法定义

### 4.1 单指数层：三因子

对每个指数 `i` 在交易日 `t` 计算：

```
f1_t = (close_t - MA60_t) / MA60_t          # 趋势偏离，权重 0.5
f2_t = MA60_t / MA60_{t-20} - 1             # 中期均线斜率，权重 0.3
f3_t = MA120_t / MA120_{t-60} - 1           # 长周期方向确认，权重 0.2
```


### 4.2 标准化（关键，不可省略）

指数点位绝对值不可比，所有因子必须转成「相对自身历史的位置」：

```
z_k(t) = 2 * rolling_percentile(f_k, window=1250) - 1     # k = 1,2,3
```

- `rolling_percentile` = 当前值在**过去 1250 个交易日（约 5 年）**取值序列中的百分位，∈ [0,1]。
- `z_k` ∈ [-1, 1]。
- **严格禁止前视偏差**：窗口只能包含 `t` 及之前的数据，收益/分位不得使用未来值。
- 历史不足 1250 根时：用 expanding window（从首日起扩张），并在输出中标记「样本不足」。

### 4.3 单指数分值

```
S_i = clip( 100 * (0.5*z1 + 0.3*z2 + 0.2*z3), -100, 100 )
```

另外直接在综合分下显示三个分组指数：大盘价值指数S_大盘价值、 S_中证500、 S_成长
```
S_大盘价值 = (S_上证50 + S_沪深300) / 2
S_中证500 = S_中证500
S_成长 = (S_创业板指 + S_科创50) / 2
```
这三个分组，各自判断牛、熊、震荡的阈值，按阈值校准章节，配置在文件，后面来调整。

### 4.4 广度因子（跨指数层）

```
breadth_t = ( 满足 close_i > MA60_i 的指数个数 ) / 5     # ∈ [0,1]
z_b(t)    = 2 * breadth_t - 1                            # ∈ [-1,1]
```

### 4.5 综合分

```
S_base = 0.40 * (S_上证50 + S_沪深300) / 2
       + 0.20 * S_中证500
       + 0.40 * (S_创业板指 + S_科创50) / 2

S      = clip( S_base * (1 + 0.3 * z_b), -100, 100 )
```

**设计说明**：广度以乘法形式调节置信度而非改变方向。5 指数方向一致 → 分值放大；方向分歧 → 分值向 0 收缩、自然落入震荡区间。这比单纯给广度一个加性权重更贴合「震荡市 = 结构分化」的市场语义。

### 4.6 状态判定

```
S < -20        -> BEAR   (熊市)
-20 <= S <= 20 -> RANGE  (震荡市)
S > 20         -> BULL   (牛市)
```

**可选平滑**：要求新状态连续保持 3~5 个交易日才确认切换，或对 `S` 做 5 日 EMA，以减少震荡市信号翻转。此开关默认关闭，需做成可配置项。

---

## 5. 阈值校准（必做，不可直接用 ±20 上线）

1. 用完整历史区间逐日计算 `S_i` 与 `S`，得到两条分值时间序列。
2. 统计三种状态的**时间占比**。
3. 合理目标：牛市 20~35%、熊市 20~35%、震荡 40~60%。
4. 若震荡占比 > 80%：说明阈值过窄或映射过紧，优先调大阈值（如 ±25/±30），或压缩分值映射系数。
5. **单指数分与综合分必须分别校准**——单指数分缺少广度因子的压缩，分布更宽，共用 ±20 会系统性高估牛/熊。
6. 校准结果（阈值、映射系数）写成配置项，不要硬编码在算法里。

---

## 6. 输出要求

1. **当日结果表**（Markdown 或 DataFrame）：

| 指数 | f1(趋势) | f2(动量) | f3(长周期) | 分值 S_i | 状态 | 是否站上MA60 |
|---|---|---|---|---|---|---|

2. **综合结果**：`S_base`、广度 `breadth`、`z_b`、最终 `S`、状态。
3. **历史分值序列**：含 date、5 个 `S_i`、`S` 的 CSV，供绘图与回测使用。
4. **回测摘要**：三态时间占比、状态切换次数、阈值校准结果。
5. 可选可视化：分值历史曲线 + 三档色带（红=牛、灰=震荡、绿=熊，遵循 A 股习惯）。

## 7. 边界情况与避坑

| 风险 | 处理 |
|---|---|
| 热身期不足 | MA120 + 60 日斜率 ⇒ 至少 180 根 K 线；分位窗口需 1250 根。不足时输出「样本不足」，不出状态判定 |
| 前视偏差 | 分位、均线、斜率全部只用 `t` 及之前数据；回测收益必须用 `t+1` 起 |
| 数据缺失 / 停牌 | forward fill 并标记；连续缺失超过 5 日则报警 |
| 指数代码错配 | 接入后先打印代码 ↔ 名称对照，人工核对一次 |
| 高相关重复计权 | 中证500 与中证1000 不同时纳入；本方案只保留 5 个指数 |
| 参数过拟合 | 阈值与权重必须在样本外区间复核（walk-forward），回测拟合度 80~90% 为合理区间，>95% 警惕过拟合 |
| 政策拐点失效 | 纯技术状态判断在重大政策落地时会失灵，输出中保留「状态基于量化信号」的提示 |

## 8. 验收标准

- [ ] 5 个指数各自输出 `S_i`，且与手工按 4.1~4.3 公式计算的结果一致（写一个单测固定某一天验证）。
- [ ] 综合分按 4.5 公式计算，`breadth` 与 `z_b` 输出正确。
- [ ] 分位标准化无前视偏差（单测：截断未来数据后，历史某日的分值不变）。
- [ ] 历史回测输出三态占比，且校准后落在第 5 节目标区间。
- [ ] 数据缓存、缺失处理、报错路径均可用。
- [ ] 全部权重、窗口、阈值均为配置项，可修改后重跑。
